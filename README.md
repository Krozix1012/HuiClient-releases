# HuiClient

A Roblox launcher for Windows.

**Download:** get `HuiClient-Setup-<version>.exe` from the [latest release](https://github.com/Krozix1012/HuiClient-releases/releases/latest) and run it.

Windows may show "Windows protected your PC" the first time, because the installer isn't code-signed. Click **More info**, then **Run anyway**.

HuiClient checks this page for new versions and shows an update button inside the app.

This repository only holds the installers. The source code is private.
